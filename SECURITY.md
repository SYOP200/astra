# Security Policy

## Supported Versions

All latest builds will have supported security. Update to the newest version to ensure the safest security.

| Version | Supported          |
| ------- | ------------------ |
| astra-0.1.0-alpha   | :x: |
| astra-0.4.0-beta| :white_check_mark: |
| astra-0.5.0-beta   | :white_check_mark:       |
| astra-1.0.0-stable | :white_check_mark: |

## Reporting a Vulnerability

You can report a vulnerability in issues or create a discussion. Make sure to tag @SYOP200 if it is important.
>[!NOTE]
> I will respond as soon as I can. <br>
> Issues or discussions tagged with @SYOP200 or high vulnerability will be worked on first.
